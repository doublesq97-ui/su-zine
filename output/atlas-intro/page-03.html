02 · 三套主题

同一份内容，
三种版式语言

JSON 根节点写 theme，或命令行用 --theme 覆盖。省略即为浅色。
03

选一套主题

light 为默认
light
白底、中文衬线标题、细灰线、双栏模块与低饱和配色
dark
近黑底、白色正文，版式与浅色完全一致，只覆盖颜色
atlas 图谱
暖米白底、单一焦橙强调色、带序号模块、流程箭头、状态表与文件清单
不包含
PDF 中间步骤：三套主题都由浏览器直接导出 PNG
04

仓库里有什么

保留 scripts/、assets/ 和 references/，不要只复制说明文件
SKILL.md
助手的完整工作流
scripts/
JSON → HTML/CSS → PNG
assets/
版式、样例：style.css、theme-dark.css、theme-atlas.css
references/
内容格式说明
examples/
示例文案与来源
tests/
构建与浏览器测试
